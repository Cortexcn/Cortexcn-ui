## What the listing gives us

Once the entry is merged into `apps/v4/registry/directory.json` in [shadcn-ui/ui](https://github.com/shadcn-ui/ui), these three things happen:

- **No setup:** `npx shadcn@latest add @cortexcn/<name>` works in any project, without adding `registries` to `components.json` first.
- **Directory page:** Cortexcn appears on the [Registry Directory](https://ui.shadcn.com/docs/directory).
- **Monitoring:** shadcn's registry health monitor starts checking the registry on a schedule.

## How upstream handles submissions

- **The file:**
  - [apps/v4/registry/directory.json](https://github.com/shadcn-ui/ui/blob/main/apps/v4/registry/directory.json) is one JSON array of entries.
  - New entries are appended at the end, not sorted in.
- **The entry schema:** [apps/v4/lib/registry-directory.ts](https://github.com/shadcn-ui/ui/blob/main/apps/v4/lib/registry-directory.ts) (zod, `.strict()`, re-read it before submitting in case it changed).
  - `name`: matches `^@[a-zA-Z0-9][a-zA-Z0-9_-]*$`, unique across the file (case-insensitive).
  - `homepage`: a URL.
  - `url`: a URL that must contain `{name}`. `{style}` is also supported.
  - `description`: a string.
  - `author`: optional string.
  - `logo`: a string holding inline SVG. Other entries use single quotes inside it and `var(--foreground)` or `currentColor`, so it follows the theme.
  - No other keys are allowed.
- **Registry requirements** ([docs](https://ui.shadcn.com/docs/registry/registry-index)):
  - Open source and publicly accessible.
  - Valid JSON that follows the registry schema.
  - A flat registry: `registry.json` and every item live at the registry root.
  - No `content` property in the index's `files` arrays.
- **Health monitor** (`apps/v4/lib/registry-health/monitor.ts` and `dry-run.ts`). After the listing it checks:
  - The index: `url` with `{name}` set to `registry` (for us, `https://ui.cortexcn.dev/r/registry.json`), parsed with `registrySchema`.
  - Every item in the index, parsed with `registryItemSchema`.
  - Weekly, one item at a time in rotation: `shadcn add @cortexcn/<item> --dry-run --yes` in a blank project whose `components.json` uses style `radix-vega` and maps the namespace to our URL.
- **What maintainers do with PRs:**
  - A bot asks for signed commits.
  - They check the site is up. They asked another submitter "is the site down?".
  - They usually copy entries into a combined PR and close the single PR with "added this to #NNNN". That is not a rejection. Follow the combined PR instead.
  - Merged means live immediately.

### Rebuilding the registry without noise

`bun run registry:build` (run from `apps/cortexcn`) rewrites a lot of unrelated files. The CLI orders keys differently, and the generators write unformatted code. Keep only real changes:

- **Registry index files:**
  - Run `../../node_modules/.bin/prettier --write packages/ui/registry.json apps/web/public/r/registry.json apps/web/public/r/<new-item>.json`.
  - The two `registry.json` files must be identical.
- **Formatting-only churn:**
  - For every other file under `apps/web/public/r`, restore it with `git checkout -- <file>` if it parses to the same JSON as `HEAD`:

    ```python
    import json, subprocess
    files = subprocess.run(["git", "diff", "--name-only", "--relative", "--", "apps/web/public/r"], capture_output=True, text=True).stdout.split()
    for f in files:
        head = subprocess.run(["git", "show", f"HEAD:./{f}"], capture_output=True, text=True, encoding="utf-8").stdout
        same = bool(head) and json.loads(head) == json.loads(open(f, encoding="utf-8").read())
        print("same" if same else "CHANGED", f)
    ```

    Run it from `apps/cortexcn`; the paths it prints are relative to that folder.

  - Restore formatting-only changes in `packages/ui/registry/examples` and `packages/ui/registry/blocks` the same way.

## Keeping the listing healthy

- **Every item in the index must keep resolving.** Each item in `packages/ui/registry.json` has to stay reachable at `https://ui.cortexcn.dev/r/<name>.json` and keep passing the dry run. When an item is removed, remove it from `registry.json` in the same deploy.
- **Rerun the health check** after any registry change, before or right after deploying.
- **Change the entry with a follow-up PR** when the URL, homepage, or description changes. Upstream precedents: "docs(registry): update @wensity URL, homepage, and description" (#11640), "chore(directory): update @soralabs URLs" (#11605).

### Paid items

The pricing page sells Pro and Ultra plans. Other listed registries sell paid items too (for example @shadcnblocks), but the listed registry itself must stay public. When checkout exists:

- **Public registry:** the free items stay in the public `@cortexcn` registry (this listing).
- **Private registry:** paid items live in a separate registry that needs a license key and is not listed, for example `@cortexcn-pro`. Buyers add it to their `components.json`:

  ```json
  "registries": {
    "@cortexcn-pro": {
      "url": "https://ui.cortexcn.dev/r/pro/{name}.json",
      "headers": { "Authorization": "Bearer ${CORTEXCN_LICENSE_KEY}" }
    }
  }
  ```

- **No paid items in the public index:** they must not appear in the public `registry.json`, or the health monitor fails on them.

## Known risks

- **Private source repo:** the Cortexcn source repository is private. The directory asks for "open source and publicly accessible". The full MIT source of every item is public inside the registry JSON, which is the case to make if a reviewer asks. A public repo for the free components would remove the question.
- **The site must stay up:** the site hosts the registry, and a failing deploy fails the monitor.

## Health check script

Save it as `registry-health.mjs` anywhere and run it from `apps/cortexcn`:

```bash
node registry-health.mjs "https://ui.cortexcn.dev/r/{name}.json"
node registry-health.mjs "https://ui.cortexcn.dev/r/{name}.json" --no-dry-run
node registry-health.mjs "https://ui.cortexcn.dev/r/{name}.json" --only=marquee,light-speed
```

- The first command runs the full check.
- `--no-dry-run` checks the schemas only.
- `--only` limits the check to a few items.
- It also works against the dev server: `"http://localhost:3000/r/{name}.json"`.
- The full dry run takes a few minutes; 77 items took about 6.

```js
// Mirrors shadcn's registry health checks (apps/v4/lib/registry-health).
import { spawn } from "node:child_process";
import { promises as fs } from "node:fs";
import os from "node:os";
import path from "node:path";
import { pathToFileURL } from "node:url";

const WEB = path.resolve("apps/web");
const { registrySchema, registryItemSchema } = await import(
  pathToFileURL(path.join(WEB, "node_modules/shadcn/dist/schema/index.js")).href
);
const CLI = path.join(WEB, "node_modules/shadcn/dist/index.js");

const registryUrl = process.argv[2] ?? "https://ui.cortexcn.dev/r/{name}.json";
const dryRun = !process.argv.includes("--no-dry-run");
const only = process.argv
  .find((a) => a.startsWith("--only="))
  ?.slice(7)
  .split(",");
const NAMESPACE = "@cortexcn";
const CONCURRENCY = 4;
const itemUrl = (name) =>
  registryUrl.replace("{name}", name).replace("{style}", "radix-vega");

async function getJson(url) {
  const response = await fetch(url, {
    headers: { accept: "application/json" },
  });
  if (!response.ok) throw new Error(`${response.status} for ${url}`);
  return response.json();
}

const index = await getJson(itemUrl("registry"));
const indexResult = registrySchema.safeParse(index);
console.log(
  `index: ${indexResult.success ? "valid" : "INVALID"} (${index.items?.length} items)`,
);
if (!indexResult.success)
  console.log(JSON.stringify(indexResult.error.issues.slice(0, 10), null, 2));
const withContent = (index.items ?? []).filter((item) =>
  (item.files ?? []).some((file) => "content" in file),
);
console.log(`index items whose files carry content: ${withContent.length}`);

const names = (index.items ?? [])
  .map((item) => item.name)
  .filter((name) => !only || only.includes(name));
const problems = [];
for (const name of names) {
  try {
    const result = registryItemSchema.safeParse(await getJson(itemUrl(name)));
    if (!result.success)
      problems.push(
        `${name}: ${JSON.stringify(result.error.issues.slice(0, 3))}`,
      );
  } catch (error) {
    problems.push(`${name}: ${error.message}`);
  }
}
console.log(`items valid: ${names.length - problems.length}/${names.length}`);
for (const problem of problems) console.log(`  ${problem}`);

async function runDryRun(name) {
  const dir = await fs.mkdtemp(path.join(os.tmpdir(), "cortexcn-health-"));
  await fs.mkdir(path.join(dir, "app"), { recursive: true });
  await fs.writeFile(
    path.join(dir, "components.json"),
    JSON.stringify({
      $schema: "https://ui.shadcn.com/schema.json",
      style: "radix-vega",
      rsc: true,
      tsx: true,
      tailwind: {
        config: "",
        css: "app/globals.css",
        baseColor: "neutral",
        cssVariables: true,
        prefix: "",
      },
      iconLibrary: "lucide",
      aliases: {
        components: "@/components",
        utils: "@/lib/utils",
        ui: "@/components/ui",
        lib: "@/lib",
        hooks: "@/hooks",
      },
      registries: { [NAMESPACE]: registryUrl },
    }),
  );
  await fs.writeFile(path.join(dir, "app/globals.css"), "");
  await fs.writeFile(
    path.join(dir, "package.json"),
    JSON.stringify({ private: true }),
  );
  await fs.writeFile(
    path.join(dir, "tsconfig.json"),
    JSON.stringify({
      compilerOptions: {
        baseUrl: ".",
        paths: { "@/*": ["./*"] },
        jsx: "preserve",
      },
    }),
  );
  return new Promise((resolve) => {
    let output = "";
    const child = spawn(
      process.execPath,
      [CLI, "add", `${NAMESPACE}/${name}`, "--dry-run", "--yes", "--cwd", dir],
      {
        cwd: dir,
        env: { ...process.env, XDG_CACHE_HOME: dir, XDG_CONFIG_HOME: dir },
        stdio: ["ignore", "pipe", "pipe"],
      },
    );
    const timer = setTimeout(() => child.kill(), 90_000);
    child.stdout.on("data", (chunk) => {
      output += chunk;
    });
    child.stderr.on("data", (chunk) => {
      output += chunk;
    });
    child.on("close", (code) => {
      clearTimeout(timer);
      fs.rm(dir, { recursive: true, force: true }).catch(() => {});
      resolve({
        name,
        ok: code === 0,
        output: output
          .replace(/\u001b\[[0-9;]*m/g, "")
          .replace(/\s+/g, " ")
          .trim()
          .slice(-400),
      });
    });
  });
}

if (dryRun) {
  const queue = [...names];
  const results = [];
  await Promise.all(
    Array.from({ length: CONCURRENCY }, async () => {
      while (queue.length > 0) results.push(await runDryRun(queue.shift()));
    }),
  );
  const failed = results.filter((result) => !result.ok);
  console.log(
    `dry runs passed: ${results.length - failed.length}/${results.length}`,
  );
  for (const failure of failed)
    console.log(`  FAIL ${failure.name}: ${failure.output}`);
}
```

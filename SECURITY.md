# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Email studio@cortexcn.dev with:

- what you found and where (the item, page, or endpoint),
- how to reproduce it,
- the impact you expect.

You will get a reply within a few days. Once a fix is out, you are welcome to be credited in the changelog.

## Scope

- The component, block, and chart source in this repository and in the published registry (`https://ui.cortexcn.dev/r`).
- The docs site and the MCP server at `https://ui.cortexcn.dev/mcp`, which is read-only and needs no sign-in.

Code copied into your own project with the shadcn CLI becomes part of that project, so keep it updated the same way you would your own code.

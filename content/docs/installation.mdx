---
title: Installation
description: Add Cortexcn components to your project with the shadcn CLI.
---

Cortexcn ships as a [shadcn registry](https://ui.shadcn.com/docs/registry). Make
sure your project is already set up with Tailwind CSS and `components.json`
(run `npx shadcn@latest init` if not).

## Add a component

Install any component straight from the registry by URL:

```bash
npx shadcn@latest add https://cortexcn.studio/r/button.json
```

### Namespaced registry

Add the registry to your `components.json` to use the short `@cortexcn` form:

```json title="components.json"
{
  "registries": {
    "@cortexcn": "https://cortexcn.studio/r/{name}.json"
  }
}
```

Then install with:

```bash
npx shadcn@latest add @cortexcn/button
```

Components are written into your project (e.g. `components/ui/button.tsx`) — you
own and can edit the code freely.
